# AGENTS.md

Графическая библиотека для монохромных дисплеев 128x64 + виджет меню. Ядро
(`src/gmg12864lib.c`, `src/gmg12864menu.c`) не знает о железе: весь вывод идёт
через таблицу функций `gmg_dev_t` (`src/gmg_types.h`), которую передают в
`GMG12864_Init(dev)`.

## Сборка и проверка

Тестов, линтеров и clang-format конфигов в репозитории нет — проверка правки
это сборка и запуск примера:

```sh
cmake -B build && cmake --build build
glem -r 128x64 -s4 & ./build/example/glem/example_glem
```

- Пример линкуется с внешней библиотекой эмулятора `glem`: заголовки
  `~/.local/include/experments`, библиотека `~/.local/lib/experments`. Нужные
  `CPATH`/`LIBRARY_PATH`/`LD_LIBRARY_PATH` уже экспортированы в `~/.bashrc`
  (`example/glem/README.md`). Без glem cmake не конфигурируется.
- `example/glem/CMakeLists.txt` собирает свои `*.c` через `GLOB_RECURSE` — новый
  файл в `example/glem/` требует повторного `cmake -B build`. При этом
  `src/gmg12864lib.c`, `src/gmg12864menu.c` и `src/dev/glem_dev.c` перечислены
  там же явно: новый модуль в `src/` добавляйте в тот же target вручную.
- Корневой `CMakeLists.txt` на не-Linux хосте форсит `CMAKE_SYSTEM_NAME Generic`
  (костыль для Windows); десктопный пример рассчитан только на Linux.

## Структура

- `src/gmg12864lib.c` — графическое ядро, шрифты `Font_3x5`/`Font_5x7`, статический
  frame buffer, весь рисующий API из `gmg12864lib.h`.
- `src/gmg12864menu.c` — виджет меню (`GMG_Menu_*`), поверх ядра.
- Бэкенды дисплея: `src/dev/glem_dev.c` (эмулятор), `src/gmg12964dev.c` (STM32 HAL,
  имя файла с опечаткой), `src/ssd1306dev.c`, `src/ssd1306spi_dev.c`.
- Аппаратные бэкенды требуют пользовательских `src/gmg12864_config.h` /
  `ssd1306_config.h`; в репозитории лежат только `*_template.h`. Десктопной сборке
  они не нужны.

## Легко упустить

- Мигание (`GMG12864_Tick`, `GMG12864_Blink_*`) работает только если `GMG12864_Tick()`
  вызывается раз в 1 мс из таймера/SysTick/RTOS.
- Если бэкенд реализует `put_pixel`, пиксели пишутся сразу в буфер устройства, а не
  во внутренний frame buffer (`src/gmg12864lib.c`, `GMG12864_Draw_pixel`), и
  `GMG12864_Update()` только флашит.
- Смещение кадра по X задаётся макросами `GMG12864_OLED` / `GMG12864_X_OFFSET` из
  конфига (`GMG12864_Update`).
- `GMG12864_Decode_UTF8` декодирует Latin, кириллицу А–я, `Ё`/`ё` и `°`; прочий
  многобайтовый UTF-8 молча уходит не в тот глиф. Инверсивная печать
  (`GMG12864_Puts_inv`) требует предварительно закрашенной белой подложки.
- `GMG_Menu_Draw` рисует в текущий кадр: перед ним нужен
  `GMG12864_Clean_Frame_buffer()`, после — `GMG12864_Update()`.
- Массив `items` передаётся в меню указателем и остаётся `const`: он должен быть
  `static` и жить всё время жизни меню, сам виджет меняет только `selected`/`top`
  в `gmg_menu_t`. Поле `value` — статическая `uint8_t`-метка пункта для
  `switch/case`, не редактируемая переменная; динамические значения настройки
  рисуйте отдельно (`GMG12864_Sprintf`), текст пункта виджет не обновит.
- В `GMG_Menu_Init` `width = 0` включает авто-ширину по самому длинному пункту
  (+ курсор `>` для `SELECTOR`, + скроллбар), `visible_rows = 0` — все пункты;
  выделение (`GMG_Menu_Up/Down`) зациклено и пропускает `enabled == false`.
- `menu->top` (прокрутка) пересчитывается только внутри `GMG_Menu_Up/Down` —
  писать в `selected`/`top` напрямую нельзя, выделение уедет за видимую область.
- `example/glem/main.c` определяет `_DEFAULT_SOURCE` ради `usleep` в strict c11 —
  не удаляйте при правках примера.

## Соглашения

- Комментарии и документация — на русском, отступ 4 пробела, секции-баннеры
  `/*---- Название ----*/`, префиксы API `GMG12864_` / `GMG_Menu_`.
- Таблицы шрифтов и битмапов обёрнуты в `// clang-format off` — не переформатируйте.
- Версия дублируется в `project(gmg12864 VERSION ...)` корневого `CMakeLists.txt`
  и в `CHANGELOG.md` — меняйте оба.
- Рабочая ветка `develop`, релизы уходят в `master`, хотфиксы — `hotfix/x.y.z`
  с мержем в `develop`. Remote: `Mcublog/gmg12864`.
